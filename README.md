One image summing up the world news of Wednesday, 18 November 2026,
as a newspaper front page: Trump lands in China for the first-ever
trilateral with Xi and Putin, Iran says its drones hit a US base in
Kuwait, Israel opens a new Gaza operation, the Quad meets in Manila,
and Cyclone Akvan bears down on Odisha — plus GTA VI, Nvidia and the
Alaska Senate race.

The front page is composed from generated illustrations and real text
laid out in code, so every headline stays crisp and legible.
`main.ts` copies `entry.png` to the output path; it runs twice and
writes the same bytes both times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
